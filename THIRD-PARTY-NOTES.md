# Third-party components

Media Workbench itself is licensed under the MIT License (see `LICENSE`). Third-party components retain their upstream licenses.

## Runtime components

- **.NET 10**: Microsoft .NET runtime; upstream MIT and third-party notices. [Source](https://github.com/dotnet/runtime).
- **Windows App SDK / WinUI 3 2.5.1**: Microsoft's runtime and original template resources; see `WINDOWS-APP-SDK-LICENSE.txt` and package/upstream notices. [Source](https://github.com/microsoft/WindowsAppSDK).
- **CommunityToolkit.Mvvm 8.4.2**: MVVM implementation/source generators, MIT. [Source](https://github.com/CommunityToolkit/dotnet).
- **CPython 3.14.8**: official x64 embeddable runtime, including the SQLite library used for the rebuildable Library index, with its original `LICENSE.txt` retained under `runtime/python` in the app bundle. [Distribution and checksums](https://www.python.org/downloads/release/python-3148/).
- **Rust standard library and Cargo dependencies**: see `native/Cargo.lock`, crate license declarations, and `licenses/third-party`. The native library uses serde/serde_json and sha2 with their dependencies, and Microsoft's `windows` crate family (MIT OR Apache-2.0) for the Media Foundation interfaces that encode videos with Windows' own H.264 encoder. Media Foundation itself is part of Windows and is not redistributed.

No third-party model weights, FFmpeg binaries, video encoders, or enhancement engines are bundled in this release. The repository-owned geometric MW icon is generated by `scripts/generate-icon.py`; original template assets are retained separately.

## Optional inference downloads

Create downloads these components into the selected data folder when the user runs setup. They are separate from the installer payload:

- **CPython 3.12.10** embeddable x64, with its original `LICENSE.txt` retained. [Official release](https://www.python.org/downloads/release/python-31210/).
- **uv 0.13.1**, MIT/Apache-2.0; extracted release archives retain upstream notices. [Official release](https://github.com/astral-sh/uv/releases/tag/0.13.1).
- **PyTorch 2.13.0 + CUDA 12.6**, Diffusers 0.35.2, Transformers 4.57.6, Accelerate 1.12.0, Hugging Face Hub 0.36.2, safetensors 0.8.0, Pillow 12.0.0, and transitive dependencies. Exact versions and distribution hashes are recorded in `profiles/sd15-cu126.lock`. Wheel license/metadata directories remain in the private installation; upstream licenses, including NVIDIA runtime terms, apply.
- **Real-ESRGAN x4plus** weights (`RealESRGAN_x4plus.pth`), downloaded at setup from the project's v0.1.0 release and pinned by SHA-256 in `profiles/upscaler-files.json`, under the **BSD 3-Clause License** (Copyright (c) 2021, Xintao Wang); see `licenses/third-party/Real-ESRGAN/LICENSE`. [Source](https://github.com/xinntao/Real-ESRGAN). The network layout in `workers/python/upscaler.py` follows the published RRDBNet architecture (ESRGAN; BasicSR) so those weights load as-is.
- **AnimateDiff motion adapter v1-5-3** (`guoyww/animatediff-motion-adapter-v1-5-3`), downloaded only when the user selects **Set up videos**, pinned to commit `2e8139b1d1269fd8a21deb96ad19455e187692eb` by size and SHA-256 in `profiles/video-files.json`; its model card is downloaded alongside. AnimateDiff is released by its authors (Yuwei Guo et al.) under the **Apache License 2.0**; see `licenses/third-party/AnimateDiff/LICENSE`. [Source](https://github.com/guoyww/AnimateDiff). Videos made with it also follow the Stable Diffusion 1.5 license below.
- **Stable Diffusion 1.5** selected files from the pinned repository commit, under **CreativeML Open RAIL-M**. The model card is downloaded alongside the files and linked before setup. [Model card / license](https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5).

Archive URLs and SHA-256 values are recorded in `profiles/sd15-cu126.json`; model files and hashes in `profiles/sd15-files.json`. No third-party account token is read for this public baseline.

## Build tools

Rust/rustup, the .NET SDK, Windows SDK BuildTools, and **Inno Setup 7.1.0** are build tools. They are not included as installer payloads. Inno Setup is obtained from its official release, verified with a pinned SHA-256, and installed into the ignored `.tools` folder when building an installer. Its commercial/noncommercial licensing conditions apply to the builder. [Inno Setup licensing](https://jrsoftware.org/isdl.php).

`packaging/dependencies.json` records the exact downloaded artifacts and their source pages. Cargo's lock file records native dependency versions and registry checksums. Model and tool redistribution will require their own inventories as those features are added.
