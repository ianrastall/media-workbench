# Third-party components

Media Workbench's application license has not yet been selected. Third-party components retain their upstream licenses.

## Runtime components

- **.NET 10**: Microsoft .NET runtime; upstream MIT and third-party notices. [Source](https://github.com/dotnet/runtime).
- **Windows App SDK / WinUI 3 2.5.1**: Microsoft's runtime and original template resources; see `WINDOWS-APP-SDK-LICENSE.txt` and package/upstream notices. [Source](https://github.com/microsoft/WindowsAppSDK).
- **CommunityToolkit.Mvvm 8.4.2**: MVVM implementation/source generators, MIT. [Source](https://github.com/CommunityToolkit/dotnet).
- **CPython 3.14.8**: official x64 embeddable runtime with its original `LICENSE.txt` retained under `runtime/python` in the app bundle. [Distribution and checksums](https://www.python.org/downloads/release/python-3148/).
- **Rust standard library and Cargo dependencies**: see `native/Cargo.lock`, crate license declarations, and `licenses/third-party`. The native library uses serde/serde_json and sha2 with their dependencies.

No third-party model weights, FFmpeg binaries, or enhancement engines are bundled in this release. The repository-owned geometric MW icon is generated by `scripts/generate-icon.py`; original template assets are retained separately.

## Build tools

Rust/rustup, the .NET SDK, Windows SDK BuildTools, and **Inno Setup 7.1.0** are build tools. They are not included as installer payloads. Inno Setup is obtained from its official release, verified with a pinned SHA-256, and installed into the ignored `.tools` folder when building an installer. Its commercial/noncommercial licensing conditions apply to the builder. [Inno Setup licensing](https://jrsoftware.org/isdl.php).

`packaging/dependencies.json` records the exact downloaded artifacts and their source pages. Cargo's lock file records native dependency versions and registry checksums. Model and tool redistribution will require their own inventories as those features are added.
